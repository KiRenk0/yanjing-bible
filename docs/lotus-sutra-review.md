# v1.6.0 法华经接入与代码审查

本次检查文本导入、出处、检索、收藏／详情、阅读、授权和发布链。新增《妙法莲华经》鸠摩罗什译本，CBETA T09n0262，七卷、二十八品、504 个正文／偈颂区块，语义索引包含 3,621 个片段。段号依所附区块顺序，不能当作其他版本的标准节号。

## 已修复的问题

1. **新经典依赖多处手写编号范围。** 原来的 `VerseKey` 分类、出处、解码和 `BibleRepository.comparisons` 写死 68–75。新增书号会被拒绝保存、误归入圣经或无法加载详情。改为查询经典目录，保留旧书号及收藏标识。全部 2,456 条经典原文检查出处往返；收藏、导出和对照测试包含书号 76。
2. **佛经出处与溢出段号解析。** 通用解析缺少“品／分”和《妙法莲华经》全名；数字溢出后 `toIntOrNull()` 返回空值，可能把错误的段号解释成整篇。补充品／分、简繁体全名、品名及“普门品”别名，显式拒绝溢出段号和范围。覆盖正常、全角、中文数字、倒序、越界和超大数字。
3. **扩充简繁表导致旧文本搜索字段失配。** 所有经典共用转换表，新增字符会改变旧文本运行时归一化，却不刷新旧 TSV 的预计算字段。导入脚本现同步刷新搜索字段及相关哈希。逐行比对确认旧正文、出处、注释／提示均未改变；已有向量输入仍是原文和独立提示，因此无需重算旧向量。只有原来的语料哈希与变更前文件相符时，才更新索引的语料哈希，防止为未知正文修改认可旧向量。新增回归逐行核对所有版本的搜索字段与实际 Android 归一化结果。
4. **源码归档会带入未审查本地文件。** 原脚本递归扫描整个 scripts 等目录，会包含未跟踪工作。本版只归档 Git 已跟踪文件；发布验证核对 ZIP 名单与 Git 名单完全一致、内容与工作区一致，并将验证绑定到发布提交。未跟踪本地工作留在本机。原签名、版本、附件哈希和正式发布防覆盖检查继续保留。

## 文本与授权核对

- 固定来源：[cbeta-org/xml-p5](https://github.com/cbeta-org/xml-p5/blob/dbdea41071e1e260ad84b72faefd4587333cf76d/T/T09/T09n0262.xml)，提交 `dbdea41071e1e260ad84b72faefd4587333cf76d`，XML 日期 2026-02-09。原始 XML 的 SHA-256 写入 `scripts/classic-sources.json`。
- 仅提取正文的二十八个 `pin`，按源顺序保存 `p`／`lg`。排除序言、校勘、音注和卷尾题记；Unicode 缺字保留源文件字符，偈颂仅整理排版空白。首段“如是我闻”，末段到大众欢喜受持、作礼而去。
- 发布检查重新从固定 XML 提取全文，与全部 504 行显示正文逐段比较，核对章序、连续键、索引／来源哈希及完整 header。源码保存原始 XML；应用保存带原始命名空间的完整来源 header、CBETA 版权及版本说明。
- 正文、衍生搜索字段与法华经索引按 CC BY-NC-SA 3.0 TW 和所附 CBETA 非营利使用条件分发，与应用自有 MIT 代码分别授权。现代汉语提示由项目另行编写、单独显示，不能冒充原文、完整翻译或权威注疏。

## 验证与边界

自动检查包括所有内置版本的归一化、经典出处往返、实际 ONNX 白话查询、索引切换、收藏／对照／导出，以及 Android 15/16 原生 Compose 中的法华经选择、搜索、收藏、复制、整品阅读和位置恢复。发布包另检查原签名、版本、SHA-256、16 KB 对齐、所有资源和压缩 DEX 的更新数据库反射入口；结果与测试数量见 Release 的 `verification.json`。

白话样例参与开发，不能当作盲测准确率。未进行物理设备验证；保留已有 Android 17 框架启动及恢复回归，不把它当作真机测试。

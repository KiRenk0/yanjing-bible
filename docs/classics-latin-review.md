# 1.5.0 经典扩充与安装包复查

范围：拉丁文圣经；儒家四书、佛教心经／金刚经、道家道德经／庄子；现代汉语离线检索；ARM64 下载包。保留 1.4.1 启动修正，用户已确认该修复版在所反馈小米 15 Pro 上可正常进入。

复查时发现并修正：

- 不能用同一书卷／章节编号直接拼接拉丁与中文圣经。新增独立拉丁书卷键和固定分节数据，核对诗篇 22:1 → 中文 23:1、拉丁但以理 4:1 → 中文 4:4、约翰 3:16；增补段落不伪造对应。合节或分节可映射多个原节，检索展示真实拉丁出处。来源数据库五个全空附录不冒充完整书卷。
- 同一宗派内有多本书后，原来按 Scripture 缓存的索引会误用上一部经典。改按实际检索语料缓存，并保留只驻留当前索引的策略；跨书检索验证心经、道德经、拉丁文及切回时不混用。
- 同一组内切书需独立保存阅读位置，同时保留旧论语存储键；普通中文／拉丁版本切换保留查询和约别筛选，切换独立经典才清空查询。
- 生成器的 OpenCC 上下文转换与 Android 的逐字转换存在差异，例如“於戏”。新增文本的检索字段统一按运行时字符映射生成，原文保持不变；对所有经典段落核对字段一致性与出处往返。
- 多部经典不应在详情里当作同一文本的译本对照。详情只列当前经典；圣经仍按映射显示各版本实际出处。阅读器按实际经典的章、分、篇和段展示，并保留古兰经原有章名、章首奉名词及双语路径。
- 版本名在搜索卡片和顶部按钮里会重复出现。顶部版本按钮新增明确的无障碍描述，自动化检查据此打开版本选择，不依赖不唯一的文本节点。
- ARM64 更新条目必须经过与通用条目相同的来源、版本、长度、哈希及签名校验；只在设备首选 ABI 是 arm64-v8a 时选择，其他架构及旧更新器保留通用包。两包检查源码版本、签名、DEX、资产和共享原生库一致。

内容校核：完整四书（论语 512、大学 16、中庸 39、孟子 690 段）、心经 7、金刚经 127、道德经 81、庄子 480 段，共 1,952 段。新增原始文件 SHA-256 固定，发布检查比较正文字符与原始 JSON／Markdown，防止摘录或截断。独立保存可复查来源和不同数据许可；APK 避免重复携带新增原始 JSON，源码包保留。

验证使用实际 ONNX 模型与生产排序代码，覆盖每部新增经典的未直接写入词典的现代改述及中拉检索；这些少量开发样例不是盲测或总体准确率。保留既有 91 项语义评估，并运行 Android 15/16 Compose 搜索／收藏／版本对照流程及 Android 17 框架启动和恢复检查。截图检查了道德经检索和中拉章节对照。最终结果与安装包体积见 Release 的 verification.json。

限制：现代提示只覆盖部分段落，语义模型可能误解否定、比喻和专业义理；没有给全部古籍编写逐段完整译文。拉丁语本身不是中文模型的主要训练语言；中文检索关联到共有的中文对应段落，不覆盖独有的增补材料。分节数据也不等于批判校勘本，应继续核对上下文。1.5.0 未经过物理 Android 设备验证；Android 17 没有 Espresso 触控全流程。按架构缩小的是下载包，安装后占用不会同比例下降。
